## 製品説明（4000文字まで）

```
「持ち物アラーム」は、保育園の持ち物準備や毎日のルーティンなど、"同じ時刻に同じチェックリストを
確認したい"というシンプルなニーズのためのリマインダーアプリです。

■ こんな方におすすめ
・保育園や幼稚園に持たせる物を、毎朝バタバタしながら思い出している
・仕事や家事のルーティンを、決まった時間にチェックリストで確認したい
・薬の飲み忘れ、持ち物の忘れ物をなくしたい
・アプリはできるだけシンプルに、余計な機能なく使いたい

■ 主な機能
・複数の「セット」（＝チェックリスト）を作成し、それぞれに好きな名前・アイコン・持ち物リストを設定
・曜日ごとの繰り返し通知。1日に複数回の通知、隔週での通知にも対応
・通知をタップすると、その日のチェックリストがすぐ開く
・全部チェックすると紙吹雪とバウンドするチェックマークでお祝い（ハプティックフィードバックつき）
・チェック状態は日ごとに記録され、月カレンダーでこれまでの達成状況を確認できる
・その日だけのメモ欄つき
・ライト／ダーク／端末設定に合わせた表示テーマ
・データはJSON形式でバックアップ・復元が可能（機種変更やアプリの再インストール時にも安心）

■ プライバシーについて
本アプリはサーバー通信を一切行いません。入力した内容はすべてお使いの端末内にのみ保存され、
広告SDKやアクセス解析、トラッキングツールも組み込んでいません。

シンプルな見た目の裏側で、忘れ物を防ぐための工夫を詰め込みました。ぜひ毎日の習慣にお役立てください。
```

### GitHub Pagesの有効化手順
1. GitHub上でこのリポジトリ（`ykoba/todo_reminder`）の **Settings → Pages** を開く
2. "Build and deployment" の Source を **Deploy from a branch** にする
3. Branch を **main**、フォルダを **/docs** にして Save
4. 数分待つと `https://ykoba.github.io/todo_reminder/` 配下で `privacy-policy.html` / `support.html` が公開される
5. GitHub Pages（無料プラン）はリポジトリが **Public** である必要がある。Privateのままにしたい場合は、
   これら2ファイルだけ別の場所（個人サイトなど）にホストする

## App Privacy（データ収集に関する質問への回答）

App Store Connect の「プライバシー」セクションでは、以下の通り回答してください。

- データを収集していますか？ → **いいえ（No, we do not collect data from this app）**
  - サーバー通信を一切行わないため、収集するデータの種類は0件

## 年齢制限（Age Rating）アンケート

共有・Web閲覧機能などは一切なし）。結果は **4+** になります。

## 提出前のその他確認事項

- **ビルド番号**: `pubspec.yaml` の `version: 1.0.0+1` がそのまま `CFBundleShortVersionString=1.0.0` /
  `CFBundleVersion=1` としてビルドに反映される。2回目以降のアップロードでは `+1` の部分
  （ビルド番号）を必ず増やす
- **スクリーンショット**: 現状の仕様（`TARGETED_DEVICE_FAMILY = "1,2"`）では iPhone に加えて iPad
  向けスクリーンショットも必要になる。iPadでの表示確認・最適化をしていない場合は、
  Xcodeの Runner ターゲット → General → Supported Destinations から iPad を外して
  iPhone専用にすると、スクリーンショット提出の手間も減らせる（後から追加も可能）
